# Incognia

> Incognia is a location identity and device fingerprinting platform for fraud prevention. Its API returns real-time risk assessments (low_risk / high_risk / unknown_risk) for onboarding signups and login/payment transactions, and accepts feedback events that tune the risk model. Authentication is OAuth 2.0 client credentials exchanged for short-lived bearer tokens. Official SDKs ship for Node.js, Python, Ruby, Java, and Go.

## APIs

- [Incognia API](https://developer.incognia.com/docs/): Real-time fraud-prevention risk assessment. Base URL https://api.incognia.com/api.

## Specs

- [OpenAPI (reconstructed)](https://raw.githubusercontent.com/api-evangelist/incognia/refs/heads/main/openapi/incognia-openapi-original.yml)

## Endpoints

- POST /v2/token — Exchange client_id/client_secret (HTTP Basic) for a bearer access token.
- POST /v2/onboarding/signups — Assess a new-user onboarding signup.
- POST /v2/authentication/transactions — Assess a login or payment transaction (set type: login|payment).
- POST /v2/feedbacks — Report a labeled event (account_takeover, chargeback, signup_accepted, payment_declined, ...).
