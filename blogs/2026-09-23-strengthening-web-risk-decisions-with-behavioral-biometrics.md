Fraud teams can assess a lot about a web session. But compared with a trusted mobile interaction, due to the browsers sandboxes the web naturally provides less direct evidence about the customer, the device they’re using, and the physical context behind the session. That can make an important question harder to answer: What signal can make this web session trustworthy?
